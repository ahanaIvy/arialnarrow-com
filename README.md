## ✨ Features

- 🎨 **Interactive Font Preview** — Real-time preview with text, size, and style controls
- ⚡ **Font Generator** — Customize letter spacing, line height, colors, and export CSS
- 📊 **Side-by-Side Comparisons** — Arial Narrow vs Arial, vs Roboto Condensed
- 🔍 **Complete Character Map** — All uppercase, lowercase, numbers, and symbols
- 📖 **Comprehensive Licensing** — Clear explanation of font licensing
- 💻 **CSS Guide** — `@font-face` implementation and web font best practices
- 🔧 **Installation Guides** — Step-by-step for Windows and Mac
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile
- ⚡ **Performance Optimized** — Excellent Core Web Vitals scores

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/arialnarrow-com.git
cd arialnarrow-com

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
